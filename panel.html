接入你的 Agent

一句话接入你的 Agent

复制一句话给能访问这台电脑的 Agent。它会读取本机接入资料，完成配置和 Skill 安装，再检查连接。

适用于支持本机 MCP 的 Agent，由 Agent 按当前宿主的方式加载配置与 Skill，并实际检查连接。

点击后，接入资料和 Skill 会保存在本机，无需另行下载。指令包含本机文件路径，不含 Key；只交给可信且能访问这台电脑的 Agent。复制成功不代表宿主已加载，仍需 Agent 实际检查。

    购买 → 激活

    购买 Key（激活码）

    通过外部渠道或联系运营购买，收款后领取激活码。此客户端暂不提供在线支付。

    标准套餐为每个订阅月30元、3000成功新感知帧，折合0.01元/帧；动作与缓存查询不额外扣帧。每账号一个任务并发，额度不结转。旧账号以实际显示的计量口径为准。

    激活 Key

    按激活码套餐开通或续期；提前续期不重置本期额度。激活成功后，客户端会准备本机连接配置。

    账号权益需要运营审核，购买或重复激活不能解除停用。请先联系运营核对。

    激活码用于绑定权益；服务连接配置由客户端自动准备和保存，不需要手动管理。
