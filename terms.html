1. 服务性质

1.1 EH 是一项 browser-use AI agent 工具。用户使用自己的模型或 agent 发出指令，EH 将用户本机浏览器中的网页信息转成结构化契约，并执行用户授权的浏览器操作。

1.2 浏览器、网页请求和与目标网站的交互发生在用户设备上。页面采样数据经连接器传至云端 EH 核心处理；处理结果返回用户的客户端和 agent。

1.3 本服务不提供代理池、IP 轮换、验证码识别或反爬绕过能力。工具能力不代表第三方网站已允许自动化访问，也不授予其内容的使用权。

2. 账号与激活

2.1 注册需提供自定义用户名、密码及邮箱，并主动接受本版本协议。邮箱通过验证码验证归属后用于账号找回；未验证邮箱不能作为找回依据。账号找回通过邮箱验证码确认归属后显示账号名称，再设置新密码；验证码及找回授权有期限且只能使用一次。激活码通过授权渠道发行，一码一账号。

2.2 账号仅限本人使用，不得转售、共享或用于未经授权的操作。用户应保管登录、API Key 与设备凭据。

2.3 运营方可依据实际服务规则和适用要求暂停账号访问。暂停不会撤销已经发生的用量记录。访问受限时，用户可在客户端提交账号申诉或通过公布的联系邮箱说明情况；提交申诉不自动解除限制，也不增加额度或延长有效期。

3. 数据处理与内容留存

3.1 网页任务内容默认不进入服务端持久存储。 页面采样仍经连接器传到云端处理。页面正文、结构、控件值、任务目标、完整执行地址和命令回包仅在处理所需的内存与经验证的易失工作区中使用；业务数据库保存固定白名单的状态、请求摘要、帧标识、时间、计量及错误代码，不保存完整回包或任务目标原文。服务端没有单次授权后长期保存正文的调试模式。

3.2 短暂交付与自动清理。 完整结果在有条数和容量上限的进程内缓存中保留，默认最多 15 分钟，配置可缩短，容量达到上限时可提前淘汰。读取不会延长该期限。任务关闭、终局或已确认结束后，受管工作目录清理；内存中冻结的只读结果仍遵守上述交付期限。闲置任务最长约 30 分钟后清理，正在执行或归属尚未核实的进程不会被误删。运行服务定时回收过期内容，配套独立清理 timer 可回收崩溃后的已确认孤儿工作区。服务端重启会失去内存结果；实际执行状态、请求号、摘要和计量仍保留，不因此重复执行动作。

3.3 客户端不提供任务历史副本。 新客户端不再自动持久保存、读取或回放网页任务正文和终局结果，也不提供任务记录页面。当前任务结果交付给用户的 agent；服务端短暂交付期限届满或内容被提前淘汰后，客户端不会从旧本地缓存补回正文，也不会据此重新执行原操作。防止重复执行所需的请求编号、提交标记和摘要仍可在本机保存，不包含完整回包。用户明确指定的结果文件导出、用户 agent 自行保留的对话或文件，以及浏览器自身的历史、profile、下载等由用户管理；旧版本已生成的缓存不会因这次升级被擅自批量删除，新客户端也不会读取这些旧正文。

3.4 继续保留的服务数据。 账号和口令散列、注册待验证邮箱及已验证邮箱、设备/Key 与权益、协议同意版本和时间、请求/会话标识、完整性摘要、执行状态、计费计量、敏感域名拦截、用户主动提交的账号申诉说明及审核处理记录、运营审计仍保存于云端。申诉功能不自动附加网页或任务正文；请勿在申诉中填写密码、验证码、Key或无关敏感资料。邮件联系会由用户自行使用邮箱发送，邮件中的资料另由相应邮箱服务及运营处理。过期登录、挑战与限流临时记录会清理；业务计量、权益及防重复执行的最小记录继续保留，本文不承诺它们按固定三年期限删除。当前没有自助完整账号注销/删除流程，用户可联系运营核实具体处理范围。

3.5 旧数据与备份。 新备份先在内存中净化，只输出元数据，不包含任务工作文件。恢复旧备份时先验证原始摘要，再净化旧回包/目标/地址并丢弃旧工作文件。旧运行库必须执行受锁保护的显式净化后才能启用新内容策略，不能仅靠改版本号视为清理完成。已经存在的外部旧备份、快照或用户另存副本需要分别处理；新版本不会擅自删除这些历史资产。

3.6 技术适用边界。 生产 CLI 要求受验证的 Linux 内存文件系统，无此条件会拒绝执行；普通磁盘测试后端仅用于明确标识的合成实验。内容归零是应用管理范围的持久化策略，不是对硬件介质、外部快照或整机取证擦除的保证。网页可能包含敏感内容，用户仍应选择有权处理的页面，避免提交不必要的信息并监督外部操作；当前没有覆盖所有控件的自动暂停采集保证。

4. 使用规则与现有技术限制

4.1 用户仅可在有权访问和处理的网站与页面上使用服务，并自行取得必要授权，遵守目标网站规则。

4.2 禁止未经授权的大规模抓取、绕过访问控制或反爬措施、侵害他人权益、对网站造成异常负载及其他违法用途。

4.3 本服务包含敏感域名基线名单、会话/动作准入检查与专属浏览器 DNS 规则。名单主要覆盖银行、支付、证券、保险、征信和医疗健康站点。名单不能覆盖所有敏感页面，DNS 规则也不能覆盖所有 IP 直连或代理场景；运行中发现受限地址后会冻结任务，不代表该页面请求从未发生。

4.4 普通公网 HTTP(S) 站点不再要求精确入口白名单；敏感域名基线及运营追加的敏感域名仍受拦截。会话创建和显式开页拒绝私有网络、非法 URL 及无法确认公网地址的域名；运行中观察到受限地址会冻结任务。域名解析、重定向与子资源请求仍可能存在边界，不能据此推定完整网络隔离。账号权益、并发/命令与帧额度等限制继续适用，用户不得修改客户端或伪造请求规避。

5. 第三方网站与任务监督

5.1 用户应遵守第三方网站的服务条款、robots 规则和适用法律；本服务不代替用户判断访问或处理行为是否合法。

5.2 涉及登录、提交、购买、发布、删除及其他有外部影响的操作，用户应确认目标与指令并监督结果。服务返回 completed 只说明该请求执行结束，不保证用户的任务目标已正确完成。

5.3 收到有效投诉或发现风险时，运营方可暂停相关访问并进行核实。当前云端保存的数据范围按第 3 条说明，不应假定仅保存元数据。

6. 可用性与责任范围

6.1 第三方网站改版、风控、验证码、网络和客户端环境可能导致请求失败或结果不确定；断线后不应直接用新请求号重放有副作用的操作，应先查询原请求并核对页面。

6.2 本文不替代正式商业服务条款，也不预先作出责任豁免或赔偿上限的法律结论。

7. 协议变更与停止使用

7.1 本协议以明确版本及正文摘要标识。客户端只能提交用户实际展示版本的接受声明；服务端正文与本机版本不同或摘要不符时，需先更新客户端并重新阅读。

7.2 已有账号缺少当前版本同意时，可登录、查询历史、关闭任务、退出及撤销凭据；发起新任务或新的浏览器执行请求前，须显式接受当前版本。不会因登录自动接受。

7.3 用户可停止使用或联系运营提出账号处理请求。当前删除能力的限制见第 3.4、3.5 条。

8. 接受方式

8.1 注册及后续重新确认均须主动勾选或通过 CLI 明确确认所展示版本。服务端校验版本与正文摘要，记录协议版本和首次接受该版本的时间；重复接受同一当前版本不刷新该时间。

8.2 服务端通过 GET /account/terms 公布当前版本和正文摘要；旧账号使用登录凭据调用 /account/terms/accept 重新确认。阅读、接受协议不消耗网页感知帧。
